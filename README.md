# IADES | Material de Programación

**Prof. Diego Fernando Penna**

Bienvenidos al espacio de GitHub dedicado al material de las materias de programación del **Instituto IADES**.

Aquí encontrarán ejemplos desarrollados en clase, ejercicios prácticos, proyectos y material complementario para acompañar el aprendizaje.

## 📚 Materias

### Programación 1

Conceptos fundamentales de programación y resolución de problemas mediante algoritmos.

**Contenidos:**
- Modularización y descomposición de problemas.
- Funciones y procedimientos.
- Validaciones y manejo de excepciones.
- Algoritmos de búsqueda y ordenamiento.

### Taller de Programación 1

Aplicación práctica de los conceptos de programación utilizando Python.

**Contenidos:**
- Desarrollo de programas en Python.
- Funciones y módulos.
- Estructuras de datos.
- Programación orientada a objetos.
- Desarrollo de proyectos integradores.

## 💻 Ejercicios y proyectos

Los repositorios contienen ejemplos y ejercicios desarrollados durante las clases.

### Visualizaciones interactivas

- **Algoritmos de ordenamiento:** material interactivo para comprender el funcionamiento de los distintos métodos de ordenamiento.

## 📌 Información importante

El material se publica con fines educativos y puede actualizarse a medida que avanzan las clases.

Los ejemplos están pensados para complementar las explicaciones y actividades realizadas en el aula.
