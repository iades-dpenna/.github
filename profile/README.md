# IADES | Programación

### Material académico — Prof. Diego Fernando Penna

Bienvenidos al espacio de GitHub dedicado a las materias de programación del **Instituto IADES**.

Este espacio reúne material educativo desarrollado y utilizado durante las clases, con el objetivo de acompañar el aprendizaje y facilitar el acceso a ejemplos y recursos prácticos.

## 📚 Contenido

Los repositorios incluyen materiales relacionados con:

- Fundamentos de programación y algoritmos.
- Resolución de problemas y pensamiento lógico.
- Estructuras de datos.
- Funciones, procedimientos y modularización.
- Algoritmos de búsqueda y ordenamiento.
- Programación orientada a objetos.
- Ejercicios prácticos y proyectos integradores.

## 💻 Material de clase

Los ejemplos y proyectos se desarrollan principalmente utilizando **Python**, además de otras tecnologías y herramientas que permiten explorar distintos conceptos de programación.

El contenido tiene fines didácticos y puede evolucionar a medida que se desarrollan las actividades académicas.

## 📌 Acerca de este espacio

Este espacio es administrado por el **Prof. Diego Fernando Penna** y está destinado a compartir material de apoyo para las clases.

El contenido publicado es de carácter educativo y no representa una comunicación institucional oficial del Instituto IADES.
